# Esempi

Dati **inventati**, per provare Contabilino e vedere com'è fatto ogni export.

| File | Contenuto |
| --- | --- |
| `contabilino-esempio.db` | database di prova: esercizio 2026, fornitori come sottoconti di 400, clienti come sottoconti di 500, le registrazioni di un anno, con incassi e pagamenti |
| `libro-giornale.pdf` | Libro Giornale |
| `saldi-conti.pdf` | Saldi Conti |
| `costi-e-ricavi.pdf` | Costi e Ricavi, con utile dell'esercizio |
| `partitari.pdf` | Partitari di tutti i conti di costo e ricavo |
| `partitari-selezione.pdf` | Partitari dei soli conti 401 e 404, scelti nell'elenco |

Per aprire l'archivio di prova: **File → Apri archivio…** in Contabilino, oppure copialo accanto a `Contabilino.exe`: la finestra di benvenuto lo propone.
